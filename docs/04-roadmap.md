### เกณฑ์ก่อนเปิดตัว

ห้ามเปิดตัวจนกว่าจะครบทั้งสามข้อ — เว็บที่ข้อมูลบางทำให้คนเข้ามาครั้งเดียวแล้วไม่กลับมา
ซึ่งเสียโอกาสมากกว่าการเปิดตัวช้าไปสองสัปดาห์:

1. มีงานที่ยังไม่หมดอายุอย่างน้อย **100 งาน**
2. ครอบคลุมอย่างน้อย **20 จังหวัด** กระจายทุกภาค
3. ทุกงานมีวันเวลาและสถานที่ครบ ตรวจสอบกับแหล่งต้นทางแล้ว

## หนี้ทางเทคนิคที่รู้อยู่แล้ว

บันทึกไว้เพื่อไม่ให้ลืม ไม่ใช่ทุกข้อต้องแก้ทันที:

| เรื่อง | ตอนนี้เป็นยังไง | ควรแก้เมื่อไหร่ |
|---|---|---|
| ข้อมูลจังหวัดซ้ำสองที่ | อยู่ทั้งใน `provinces.ts` และ SQL seed ต้องแก้พร้อมกันเอง | เมื่อย้ายไป Supabase แล้วให้ TypeScript อ่านจาก DB แทน |
| ยังไม่มีเทสต์ | ไม่มีเลย | ก่อนมีคนที่สองเข้ามาช่วยเขียนโค้ด — เริ่มจาก `format.ts` และ `geo.ts` ที่เป็นฟังก์ชันบริสุทธิ์ ทดสอบง่าย |
| หน้ารายละเอียดงาน render แบบ dynamic ทุกครั้ง | ยังไม่ได้ cache | เมื่อมีงานเกิน ~500 งาน ให้ใช้ ISR หรือ `"use cache"` |
| แผนที่ในหน้ารายละเอียดงานเป็น iframe จาก OSM | ใช้ได้ดีกับหมุดเดียว | เมื่อต้องแสดงหลายหมุดพร้อมกันในหน้าเดียว |
| หน้า `/map` แสดงได้แค่ระดับจังหวัด | แหล่งข้อมูลมีระดับอำเภอ/ตำบลให้ใช้ต่อได้ (`th_adm2` / `th_adm3`) | เมื่อจังหวัดใหญ่ๆ มีงานเยอะจนต้องซูมดูรายอำเภอ |
| แผนที่ยังไม่รองรับลากเลื่อน/ซูมด้วยนิ้ว | ซูมได้เฉพาะตอนกดเลือกจังหวัด | เมื่อผู้ใช้เริ่มบ่นว่าจังหวัดเล็กๆ กดยากบนมือถือ |
