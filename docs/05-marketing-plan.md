# แผนการตลาดและการเติบโต

> อัปเดตล่าสุด: 2026-08-19

## ปัญหาหลัก: cold start

เว็บรวมอีเวนต์มีปัญหาไก่กับไข่แบบคลาสสิก — ผู้ใช้ไม่มาถ้าไม่มีงาน ผู้จัดงานไม่ส่งงานถ้าไม่มีผู้ใช้

**ทางออกคือทีมงานลงมือกรอกข้อมูลเองก่อน** ไม่ต้องรอให้ระบบ crowdsource ทำงาน
ยอมเหนื่อยช่วงแรกเพื่อให้เว็บมีค่าตั้งแต่คนแรกที่เข้ามา นี่คือเหตุผลที่เกณฑ์ก่อนเปิดตัว
ใน `04-roadmap.md` กำหนดไว้ที่ 100 งาน / ครบ 7 จังหวัดภาคตะวันออก

**กลยุทธ์เสริม: เจาะลึกก่อนกระจายกว้าง** เลือกจังหวัดหรือหมวดหมู่ที่เราหาข้อมูลได้แน่นจริง
แล้วทำให้ครบถ้วนที่สุด ดีกว่ามีงานจังหวัดละ 1 งานกระจายบางทั่วประเทศ — คนที่ค้นหา
"งานเทศกาลชลบุรี" แล้วเจอ 15 งานจะกลับมาอีก ส่วนคนที่เจอ 1 งานจะไม่กลับมา นี่คือกลยุทธ์
ที่ถูกนำมาใช้จริงโดยจำกัดขอบเขตทั้งเว็บไว้ที่ภาคตะวันออก (ดูเหตุผลใน `01-prd.md`) แทนที่จะ
เลือกเจาะจังหวัดแบบไม่ติดกันซึ่งดูแลข้อมูลเองได้ยากกว่า

## ช่องทางเติบโต เรียงตามลำดับความสำคัญ

### 1. SEO — ช่องทางหลัก

เป็นช่องทางที่เหมาะที่สุดเพราะ **ไม่ต้องใช้งบ** และ **ความต้องการมีอยู่แล้ว** คนพิมพ์
"งานเทศกาลใกล้ฉัน" หรือ "งานประจำปีขอนแก่น" ในกูเกิลอยู่ทุกวัน แค่ต้องทำให้เจอเรา

สิ่งที่ทำไว้แล้วในโค้ด:

- SSR ทุกหน้า บอทเห็นเนื้อหาเต็ม
- **JSON-LD `schema.org/Event`** ทำให้ Google แสดงผลค้นหาแบบพิเศษ มีวันที่และสถานที่
  ในหน้าผลลัพธ์เลย ได้พื้นที่มากกว่าและคนคลิกมากกว่าผลธรรมดา
- **sitemap รวมหน้าที่กรองแล้ว** เช่น `/events?province=chiang-mai` เพราะตรงกับคำค้นจริง
- หัวข้อหน้าเปลี่ยนตามตัวกรอง — "งานดนตรี ในเชียงใหม่" ไม่ใช่ "ค้นหางาน" เฉยๆ

สิ่งที่ต้องทำต่อ:

- เปลี่ยน URL ที่กรองแล้วเป็น path จริง (`/chiang-mai`) แทน query string ใน Phase 2
- เขียนบทความคู่มือเที่ยวเพื่อจับ long-tail keyword
- สมัคร Google Search Console ตั้งแต่วันแรกที่ deploy เพื่อดูว่าคนค้นด้วยคำอะไรมาเจอเรา

### 2. แชร์ผ่าน LINE และ Facebook

คนไทยส่งลิงก์ให้เพื่อนผ่าน LINE เป็นหลัก การแชร์หนึ่งครั้งในกลุ่มเพื่อน 30 คน
มีค่ามากกว่าโฆษณาที่ยิงไปหาคนแปลกหน้า 30 คน

จุดที่ต้องทำให้ดี: **OG image** ลิงก์ที่แชร์แล้วขึ้นแค่ตัวหนังสือกับคนกดน้อยกว่าลิงก์ที่มีรูป
ชื่องาน และวันที่ชัดเจนมาก — จึงอยู่ใน checklist ของ Phase 1

### 3. กลุ่มชุมชนที่มีอยู่แล้ว

แทนที่จะสร้างผู้ชมใหม่ ให้ไปที่ที่คนสนใจเรื่องนี้อยู่แล้ว:

| กลุ่ม | เข้าถึงยังไง |
|---|---|
| กลุ่ม Facebook ประจำจังหวัด | โพสต์รวมงานประจำเดือนของจังหวัดนั้น พร้อมลิงก์ |
| กลุ่มสายรถ / คาร์มีท | เป็นชุมชนที่แน่นและข้อมูลกระจัดกระจายมาก — ได้ประโยชน์จากเราชัดเจน |
| กลุ่มท่องเที่ยว / แบกเป้ | โพสต์ตอนใกล้ช่วงวันหยุดยาว |
| เพจผู้จัดงานรายเล็ก | ทักไปบอกว่าลงงานให้ฟรีแล้ว ขอให้ช่วยแชร์ |

**สำคัญ**: ทุกโพสต์ต้องให้คุณค่าก่อน (รวมงานให้ดูเลย) ไม่ใช่แค่ขอให้คนมาเข้าเว็บ

### 4. Flywheel: ให้ผู้ใช้ช่วยเติมข้อมูล

เป้าหมายระยะยาวคือทีมงานไม่ต้องกรอกเองทั้งหมด ปุ่ม "แจ้งงาน" จึงอยู่เด่นในทุกหน้า
ตั้งแต่วันแรก แม้ตอนนี้ยังต้องรออนุมัติทุกงานก็ตาม

ตัวชี้วัดที่บอกว่า flywheel เริ่มหมุน: **จำนวนงานที่คนส่งเข้ามาเองต่อสัปดาห์เพิ่มขึ้นต่อเนื่อง**

### 5. พาร์ทเนอร์ระยะยาว

หน่วยงานท่องเที่ยวจังหวัดและ ททท. มีข้อมูลงานทางการที่เชื่อถือได้ และการได้ชื่อไปอยู่
ในช่องทางของหน่วยงานรัฐคือ PR ฟรีที่ซื้อไม่ได้ — แต่ติดต่อได้ผลก็ต่อเมื่อเรามีเว็บที่ใช้งานจริง
และมีตัวเลขผู้ใช้ให้ดูแล้ว จึงเป็นเรื่องของ Phase 2–3 ไม่ใช่ตอนนี้

## สิ่งที่ไม่ควรทำช่วงแรก

- **ซื้อโฆษณา** — ยังไม่รู้ว่าอะไรทำให้คนกลับมา จ่ายเงินตอนนี้คือจ่ายเพื่อเรียนรู้ในราคาแพง
- **ทำแอป native** — เพิ่มงานเป็นเท่าตัวโดยยังไม่รู้ว่าคนอยากได้จริงไหม
- **เปิดให้โพสต์ได้เองโดยไม่ตรวจ** — งานปลอมหรือข้อมูลผิดทำลายความน่าเชื่อถือเร็วกว่าที่จะกู้คืนได้

## ตัวชี้วัดที่ควรดูทุกสัปดาห์

1. จำนวนงานที่ยังไม่หมดอายุในระบบ
2. สัดส่วนผู้เข้าเว็บที่กด "งานใกล้ฉัน"
3. งานที่คนส่งเข้ามาเองต่อสัปดาห์
4. Organic traffic และคำค้นที่พาคนมา (จาก Search Console)
